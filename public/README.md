## Cómo obtener tu Avatar

1. Ve a [Ready Player Me](https://demo.readyplayer.me/avatar)
2. Crea tu avatar personalizado
3. Al finalizar, haz clic en **"Download"** o copia la URL del avatar
4. Si tienes la URL (termina en `.glb`), descárgala
5. Renombra el archivo a `avatar.glb`
6. Coloca el archivo `avatar.glb` en esta carpeta (`public/`)

### URL de ejemplo para probar:
Si no quieres crear un avatar, puedes usar este de ejemplo:
```
https://models.readyplayer.me/64c3a7e0e1e5f9d3c8b4a2f1.glb
```

Descárgalo y guárdalo como `avatar.glb` en esta carpeta.
